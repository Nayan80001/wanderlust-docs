# Word list

| Word | Kid-friendly meaning |
|---|---|
| ALB | Application Load Balancer: a front door that sends website traffic to the right service |
| Ansible | A tool that installs and configures software on computers |
| Argo CD | A controller that compares Kubernetes with the settings stored in Git |
| CI | Continuous integration: automatically checking code whenever it changes |
| CD | Continuous delivery: safely preparing and applying a new version |
| Container | A packaged application plus the pieces it needs to run |
| ECR | Amazon's private shelf for storing container images |
| GitOps | Managing the desired running setup through version-controlled Git files |
| Helm | A package/template system for describing Kubernetes applications |
| Ingress | A Kubernetes traffic director that sends web requests to the right service |
| Instance | An AWS virtual machine, like a rented computer |
| Kubernetes | A system that schedules and restarts containers across computers |
| Loki | A service that stores and searches text logs |
| NAT gateway | A one-way-style exit that lets private machines reach the internet for downloads |
| NodePort | A port on a Kubernetes node that can receive traffic from an approved network source |
| Prometheus | A system that collects numbers (metrics) and checks alert rules |
| Quality gate | A set of code-health conditions that must pass before a build continues |
| SSM | AWS Systems Manager: a controlled way to manage machines without opening SSH |
| Terraform | Code that describes which cloud resources should exist |
| VPC | A private network space inside AWS |
